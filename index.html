Como o Tailwind CSS funciona?

O Tailwind CSS é um framework utility-first, o que significa que ele utiliza pequenas classes prontas para estilizar elementos diretamente no HTML. Em vez de criar estilos personalizados no CSS, você combina essas classes para construir interfaces rápidas, consistentes e modernas.

Cores

Com classes como bg-blue-500, é possível aplicar cores de forma rápida e consistente, seguindo uma paleta padronizada.

Tipografia

Texto pequeno

Texto médio

Texto grande

O controle de texto é feito com classes como text-xl e font-bold, permitindo ajustar tamanho e peso facilmente.

Espaçamento

p-2
p-4
p-6

Espaçamentos são aplicados com classes como p-4 e m-2, facilitando o controle do layout.

Layout e Responsividade

O Tailwind CSS facilita a criação de layouts modernos usando Flexbox e Grid diretamente no HTML, além de oferecer um sistema de responsividade simples com breakpoints como md e lg.

Flexbox na prática

flex-col (mobile)

md:flex-row (desktop)

Grid Responsivo

1 coluna no mobile

2 colunas no tablet

3 colunas no desktop

Breakpoints

Tailwind usa prefixos para responsividade:

sm: md: lg: xl:

Escrevendo com Tailwind CSS

No Tailwind, os estilos são aplicados diretamente no HTML através de classes utilitárias, sem necessidade de CSS separado.

Botão estilizado 

      <button class="bg-blue-600 text-white px-6 py-3 rounded-lg
      hover:bg-blue-700 hover:scale-105
      active:scale-95 transition-all duration-200">
        Clique aqui
      </button>

Card simples 

      <div class="bg-white dark:bg-gray-900
      p-6 rounded-xl shadow-md
      hover:shadow-xl transition">

        <h2 class="text-xl font-bold text-gray-800 dark:text-white mb-2">
          Título do card
        </h2>

        <p class="text-gray-600 dark:text-gray-400">
          Conteúdo do card usando Tailwind.
        </p>

      </div>

Cada classe no Tailwind representa uma propriedade CSS, permitindo construir interfaces completas diretamente no HTML.
