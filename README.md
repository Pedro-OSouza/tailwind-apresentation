# Tailwind CSS Project

Este projeto foi desenvolvido para fins acadêmicos, com o objetivo de demonstrar o uso do Tailwind CSS na criação de interfaces modernas e responsivas.

---

## 🚀 Tecnologias utilizadas

- HTML5
- Tailwind CSS
- JavaScript (vanilla)
- Vite (opcional, dependendo da configuração do projeto)

---

## 📦 Como rodar o projeto

### 1. Clonar o repositório

  ```bash
  git clone https://github.com/seu-usuario/seu-repositorio.git
  ```

2. Acessar a pasta do projeto
```bash
  cd nome-do-projeto
```

4. Instalar dependências

Se o projeto estiver usando Node/Vite:
```bash
npm install
```

4. Rodar o projeto
```bash
npm run dev
```
6. Abrir no navegador

Após iniciar o servidor, acesse:

http://localhost:5173

📁 Estrutura do projeto\
├── index.html\
├── src/\
│   ├── style.css\
│   └── assets/\
└── README.md\

## 🎯 Objetivo

Demonstrar o uso do Tailwind CSS para construção de interfaces com:

Utility-first classes
Responsividade
Dark mode
Componentização visual
